# ArcellaJava — Sistema di noleggio biciclette

## Descrizione

Progetto sviluppato in Java per esercitarsi nella programmazione orientata agli oggetti attraverso la modellazione di un sistema di noleggio biciclette.

Il codice comprende diverse classi dedicate alle biciclette, alle persone e alla gestione del noleggio.

## Funzionalità e componenti

- **Bici**: rappresentazione di una bicicletta.
- **BiciElettrica**: specializzazione dedicata alle biciclette elettriche.
- **BiciNonPrestabile**: gestione di biciclette non disponibili per il prestito.
- **Persona**: rappresentazione delle persone coinvolte nel sistema.
- **CasaBici** e **Noleggio**: classi dedicate alla gestione del servizio di noleggio.
- **YellowPages**: componente aggiuntivo del progetto.
- **Main**: punto di ingresso per l'esecuzione del programma.

## Tecnologie utilizzate

- Java
- Programmazione orientata agli oggetti (OOP)

## Esecuzione

Per eseguire il progetto, è necessario disporre di un JDK compatibile con il codice.

Il programma può essere avviato dalla classe `Main`, utilizzando il proprio ambiente di sviluppo Java oppure configurando la compilazione da terminale.

## Obiettivo didattico

Il progetto ha lo scopo di consolidare le basi della programmazione Java e l'organizzazione del codice attraverso classi e relazioni tra oggetti.
